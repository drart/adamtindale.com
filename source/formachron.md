# Formachron

## Project Overview
**Formachron** (formerly gridquencer) is an ongoing software project to create a **polymetric, polyrhythmic, polyphasic sequencer instrument** for live music performance and production. The innovative interface utilizes grid notation in a novel way to quickly express and augment the number of subdivisions in a beat, enabling the creation of **ansiorhythmic patterns** (patterns that exist outside traditional rhythmic structures).
